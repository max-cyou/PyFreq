# PyFreq

API для поиска правильного варианта ответа по вопросам. PyFreq получает веб-выдачу через DDGS и ранжирует варианты по найденным контекстам.

Сделано в качестве эксперимента, протестировано на школьных тестах (не рекомендую использовать для этого ;)

## Запуск

Проект проверялся на Python 3.14.

```bash
git clone https://github.com/max-cyou/PyFreq.git
cd PyFreq

python3.14 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt

python main.py
```

Сервер будет доступен по адресу `http://127.0.0.1:8000`.

## API

> Документация доступна после запуска по локальному адресу `http://127.0.0.1:8000/api/docs`

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/` | Информация о приложении |
| GET | `/health` | Проверка доступности сервера |
| POST | `/api/v1/solve/text` | Решение текстового вопроса |
| GET | `/api/docs` | Swagger UI |

### Тестовый запрос (пример)

```bash
curl 'http://127.0.0.1:8000/api/v1/solve/text' \
  -H 'Content-Type: application/json' \
  --data-raw '{
    "question": "Кто написал роман Преступление и наказание?",
    "answers": ["Толстой", "Достоевский", "Тургенев", "Гончаров"]
  }'
```

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `question` | string | Обязательный | Непустой текст вопроса |
| `answers` | string[] | Обязательный | Не менее двух вариантов ответа |
| `timeout` | integer | `20` | Таймаут запроса к поисковику в секундах, больше нуля |
| `backend` | string | `auto` | Поисковая система |
| `max_results` | integer | `1` | Максимальное число близких вариантов в `candidates`, не менее одного |
| `confidence_gap` | number | `0.1` | Допустимое отставание оценки кандидата от лидера, от `0` до `1` |

Доступные `backend`: `auto`, `brave`, `duckduckgo`, `grokipedia`, `mojeek`, `startpage`, `wikipedia`, `yahoo`.

### Ответ

Пример формата успешного ответа:

```json
{
  "answer": "Достоевский",
  "index": 1,
  "confidence": 1.0,
  "candidates": [
    {
      "answer": "Достоевский",
      "index": 1,
      "confidence": 1.0
    }
  ]
}
```

`index` — позиция в исходном списке `answers`, начиная с нуля.

`confidence` — доля положительной оценки варианта среди всех вариантов. Это оценка ранжировщика, а не калиброванная вероятность правильного ответа.

`candidates` отсортированы по убыванию оценки. При `confidence_gap: 0.1` и оценках `0.52`, `0.47`, `0.01` в список попадут первые два варианта, если `max_results` позволяет. После фильтрации оценки не пересчитываются. `max_results` задаёт верхнюю границу количества кандидатов.

При отсутствии положительных свидетельств или слишком близких оценках лидеров возвращаются `answer: null`, `index: null`, `confidence: 0.0`. Если `max_results > 1`, при неоднозначном выборе могут вернуться близкие кандидаты.

## Как выбирается ответ

1. Вопрос очищается от поддерживаемой разметки и передаётся в DDGS. Поиск использует регион `ru-ru` и запрашивает до 100 результатов.
2. Заголовки и описания разбиваются на контексты. Повторяющиеся источники и фрагменты отбрасываются.
3. Текст лемматизируется через `pymorphy3`. Для формул применяется отдельная нормализация: знаки, степени, дроби и поддерживаемые команды LaTeX сохраняют структуру.
4. Варианты оцениваются по релевантности вопросу, позиции источника и эвристикам полярности. Однозначные явные определения имеют приоритет.
5. Возвращается лучший вариант и, при необходимости, близкие кандидаты.

Качество зависит от содержания выдачи и формулировки вопроса. Нормализация LaTeX поддерживает базовые конструкции, включая `\frac`, `\sqrt`, степени и функции; вычисления формул не выполняются.

## Структура

```text
main.py                # FastAPI и обработчики запросов
schemas.py             # Модели запроса и ответа
requirements.txt
core/
  search.py            # Поиск и повторные попытки
  matching.py          # Лемматизация, формулы и совпадения
  ranking.py           # Оценка контекстных свидетельств
  solver.py            # Выбор ответа и близких кандидатов
benchmarks/
  datasets/            # Вопросы и правильные ответы
  snapshots/           # Сохранённые выдачи
  results/             # Локальные отчёты
  run.py
```
